Privacy Policy

Last updated: August 28, 2026

Summary: Animanoizing Bot is a personal tool that posts anime artwork to Pinterest boards. We do not collect, sell, or share any personal data with third parties. The only data stored is a local list of processed image URLs to avoid duplicates.

1. Who We Are

Animanoizing Bot ("the Bot", "we", "us") is a personal automation tool developed by an individual developer to automatically discover and post anime artwork to Pinterest. The service is not a commercial product and is not operated as a business.

Contact: github.com/nm969989-cmd

2. What Data We Collect

The Bot collects and stores minimal data necessary to function:

  • Image URLs: URLs of images already processed are stored locally in a SQLite database to prevent duplicate uploads. This data is not transmitted to any third party.
  • Pinterest Access Token: A Pinterest API access token is stored securely as an environment variable on the hosting server. This token is never logged or shared.
  • Telegram Chat ID: The Telegram chat ID of the bot administrator is stored to allow control commands. This is stored as an environment variable only.

3. How We Use Data

  • To authenticate with the Pinterest API and post pins on the owner's behalf
  • To track which images have already been processed (deduplication)
  • To send status notifications to the bot administrator via Telegram

We do not use any collected data for advertising, analytics, or any purpose other than the bot's core functionality.

4. Pinterest API Usage

The Bot uses the Pinterest API v5 to create pins on the account owner's boards. The Bot:

  • Only posts to boards owned by the authenticated user
  • Does not read or modify any other users' data
  • Does not store Pinterest user data beyond what is needed to complete the pin upload
  • Complies with Pinterest's API Terms of Service and Developer Guidelines
  • Respects Pinterest's rate limits (maximum 15 posts per day, well within the 300/day limit)

5. Data Storage and Security

  • All sensitive credentials (API tokens) are stored as encrypted environment variables on Render.com
  • The image deduplication database is stored locally on the server and is never transmitted
  • No personal data is stored in any external database or third-party service

6. Third-Party Services

The Bot interacts with the following third-party services:

  • Pinterest API: To post pins — governed by Pinterest's Privacy Policy
  • OpenRouter AI: Image captions are generated via OpenRouter's API. Images are sent to their API for analysis — governed by OpenRouter's Privacy Policy
  • Amazon Associates: Affiliate links are generated for relevant products — governed by Amazon's Privacy Policy
  • Render.com: Hosting platform — governed by Render's Privacy Policy

7. Your Rights

Since this is a personal tool operating on the owner's own Pinterest account, there is no user data collected from third parties. If you believe any of your data has been inadvertently collected, please contact us via GitHub and it will be deleted immediately.

8. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected by updating the "Last updated" date at the top of this page.

9. Contact

For any privacy-related questions, please open an issue on our GitHub repository.
